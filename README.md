# Лабораторна робота №10: Організація двовимірних (багатовимірних) масивів

Виконав: Шевченко Нікіта Вікторович, група ІСТ-21, варіант 17.

## Структура репозиторію

* task1_even_rows.cpp — кількість парних чисел у кожному рядку матриці 4x3
* task2_even_cols.cpp — кількість парних чисел у кожному стовпчику матриці 6x4
* task3_row_sums.cpp — сума елементів кожного рядка матриці 5x7
* task4_col_sums.cpp — сума елементів кожного стовпчика матриці 4x6
* task5_max_element.cpp — пошук максимального елемента та його номера у матриці 3x4
* task6_min_element.cpp — пошук мінімального елемента та його номера у матриці 4x7
* task15_diagonals_sum.cpp — обчислення суми елементів по діагоналях матриці 3x3
